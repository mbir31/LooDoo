# 🎲 LooDoo : লুডু 🇧🇩

🇧🇩 বাংলাদেশের লুডু, এবার আপনার বন্ধুদের সাথে — যেখানেই থাকুন!

LooDoo is a Bangladeshi-inspired multiplayer Ludo experience built for the way we actually play Ludo in Bangladesh.

বন্ধুদের সাথে আড্ডা, পরিবারের সাথে এক ফোনে খেলা, দূরে থাকা বন্ধুদের সাথে অনলাইন ম্যাচ, অথবা একা AI-এর বিরুদ্ধে লড়াই — LooDoo brings the familiar Bangladeshi Ludo experience into a modern, fun and beautifully designed game.

🇧🇩 MADE FOR BANGLADESHI LUDO LOVERS

LooDoo pays special attention to the small things that make local Ludo feel familiar.

🎲 Bangladeshi-style rules

Including mechanics such as:

- 6 required to bring a token out
- Three consecutive sixes can cancel the turn
- Token capturing
- Capture-related bonus turns
- Safe/star cells
- Blockades
- Home-path movement
- Overshoot prevention

The goal is simple:

«যে লুডু আমরা ছোটবেলা থেকে খেলেছি, সেই অনুভূতিটাকে ডিজিটালভাবে ফিরিয়ে আনা।»

🚀 START PLAYING

🌐 Play instantly

👉 [PLAY LooDoo](https://loodoo.vercel.app)

LooDoo is built as an installable Progressive Web App.

You don't need to go through a traditional app-store installation process.

---

📱 Android

1. Open [loodoo.vercel.app](https://loodoo.vercel.app) in Chrome, Edge or another supported browser.
2. Tap Install App if available.
3. Alternatively, open the browser menu and choose Add to Home Screen / Install App.
4. Launch LooDoo from your home screen.

---

🍎 iPhone / iPad

1. Open [loodoo.vercel.app](https://loodoo.vercel.app) using Safari.
2. Tap Share.
3. Select Add to Home Screen.
4. Tap Add.

LooDoo can then launch like an installed web app.

---

💻 Desktop

Open the game in a supported desktop browser and use the browser's install option when available.

🛠️ BUILT WITH MODERN WEB TECHNOLOGY

LooDoo combines modern frontend technology with real-time multiplayer infrastructure.

| Technology | Purpose |
| :--- | :--- |
| ⚛️ React 19 | User interface |
| 🔷 TypeScript | Application logic |
| ⚡ Vite | Development & build tooling |
| 🎨 Tailwind CSS | Styling |
| ✨ Motion | Animations |
| ⚡ WebRTC DataChannel | Ultra-low latency (<30ms) peer-to-peer game sync |
| 🔥 Firebase Firestore | Real-time cloud persistence & room discovery |
| 🔐 Firebase Authentication | Guest authentication & sessions |
| 🎨 HTML5 Canvas | Match summary generation |
| 🔊 Web Audio API | Game sounds & Bangla soundboard |
| 📦 PWA | Installable web experience |
| ☁️ Vercel | Hosting & deployment |

🔒 PRIVACY & SECURITY

LooDoo is designed around a lightweight, friction-free multiplayer experience.

🛡️ Key principles

- No mandatory account creation for casual play
- Anonymous authentication for multiplayer sessions
- Firestore security rules
- HTTPS deployment
- Fast and resilient client-side state handling
